# Concepts

**Docs home:** [Top Down Planning documentation](../README.md)

**Audience:** newcomers and anyone who needs shared vocabulary before running or operating TDP.

These pages define what Top Down Planning is and the terms later sections reuse. Workflows, the operator manual, and architecture link here instead of redefining the same words.

## Pages

- [Overview](overview.md) — what TDP is, the problem it solves, use cases, and non-goals
- [Plan tree](plan-tree.md) — items, contracts, aggregation, dependencies, and readiness
- [Quality loop](quality-loop.md) — batches, evidence, completion, validation, review, and outcomes
- [Lifecycle terms](lifecycle-terms.md) — run status, phase, review stage, revisions, recoverable versus terminal
- [Roles](roles.md) — planner, producer, reviewer, operator, and orchestration engine

A newcomer typically reads the [overview](overview.md), then [lifecycle terms](lifecycle-terms.md), then follows the [first-run walkthrough](../workflows/first-run.md). Runtime agents start at the [agent hub](../agents/README.md) and use this section when a protocol page points at a term.
